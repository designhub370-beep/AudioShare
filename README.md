# AudioShare

Android prototype for selecting up to five paired Bluetooth earbuds or speakers with individual volume controls.

GitHub Actions builds a debug APK on pushes to main or from the Actions tab.

Important: this prototype implements the device-selection UI. Android does not provide a universal third-party API for independently routing arbitrary phone audio to five classic Bluetooth A2DP devices. Real synchronized multi-output audio needs compatible phone/vendor support, Bluetooth LE Audio/Auracast, or dedicated transmitter hardware.
